# Shared contracts (v1, implementing specification v2.5)

Integrator owns src/protocol.ts and convex/schema.ts. Request shared changes; do not edit them from implementation lanes.

- Requests bind protocol/client versions, supported capabilities, backendId, projectId and requestId. Both directions enforce compatibility. Authenticate before replay; credential/run + operation + request ID identifies replay; canonical payload digest prevents changed-payload reuse. Server time controls authority.
- Project agents draft/read/request admission. Humans alone approve exact content revision/hash, trust routing, membership, limits and overrides. Run grants bind member/project/task/run/epoch/goal revision/live lease. Supervisor credentials bind machine/project and evidence-only lifecycle calls, remain separate from worker grants.
- Independently owner-provisioned artifact-verifier credentials attest exact Git/scan/PR runner evidence for their machine/project/member. They cannot settle lifecycle capacity; supervisors cannot verify code. Neither credential is provided to model-controlled worker tools. Actual filesystem/helper separation is a qualification gate.
- Scan chunk completion proves transmission only. Authoritative coverage requires the artifact verifier's full sorted baseline-to-candidate diff digest/count, exact HEAD/tree/epoch and task/project path boundaries. An empty model-declared upload cannot certify a changed tree. `configVersion` invalidates security configuration/grants; rule `policyVersion` updates remain retrievable by current sessions.
- No generic state setter. Task result, grant revocation, process exit and capacity release are separate facts. Unknown launch or failed stop retains reservation and task-wide hold. Accepted PR alone never frees capacity. Late supervisor evidence can settle only its own reservation, never resurrect a task/new epoch.
- Capabilities bind OS, harness/version, adapter/probe version, permission configuration digest and Git policy digest; digests never include secret values. Missing/stale/fixture evidence cannot qualify real managed admission. Harness auth and tool credential isolation are separate checks.
- Capture manifest binds exact execution base/revision, source HEAD, selected paths/types/modes/blob identities, exclusions, tree, progress hash and verification. Snapshot sole parent is the verified remote-present execution base, never a fetched newer tip. PR publication applies the same safe-history policy to its actual artifact; verify the final review commit and relevant live base.
- External Git/process/PR effects use stable IDs and reconciliation. DB transactions are not external exactly-once guarantees. Ready acceptance must revalidate current authority.
- Plugins connect via stdio MCP directly to Convex. Hooks independently fetch state; no memory queue. Receipt labels distinguish bytes offered from model acknowledgement; unresolved conflict blocks publication.
- Local fixtures prove primitives only. No agent chooses deployment, paid resource, external sharing destination or protected approval. No merge/deploy tools. Keep unsupported modes fail-closed.
