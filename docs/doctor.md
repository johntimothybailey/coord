# Host evidence

`coord doctor --json` reports versioned discovery and disposable primitive evidence. `runDoctor(options?: DoctorOptions): Promise<DoctorReport>` is the programmatic entry point. Options set bounded command timeout/output limits or disable disposable fixtures. It never installs plugins, changes harness settings, starts a paid model turn, approves protected actions or contacts an arbitrary deployment.

Host discovery runs only CLI version/help, plugin listing and Codex login status commands. Raw stdout/stderr is withheld because these commands can include private configuration. Reports retain exact fixed argv, exit code, bounded-output result, OS/Node/harness versions and allowlisted observations. No credential/config file contents are read or hashed. Configuration digests cover host/version, adapter/probe versions, resolved binary identifiers, Codex config file metadata and observed permission flag support. Effective permissions remain explicitly unverified; metadata and help do not establish runtime isolation. Antigravity configuration location is unverified. These conservative digests cannot qualify a host.

Disposable fixtures initialize isolated local Git repositories, transfer a coord ref to a local bare remote, verify exact object/content identity, and observe/stop a temporary POSIX process group with boot/start identity. The fixtures use a restricted environment and temporary Git configuration. Their evidence is always `kind: fixture`, cannot satisfy `requireCapability`, and is removed after the probe. This proves local primitives, not production harness stop behavior, Git-host policy, remote availability or safe publication history.

All advertised mode gates remain BLOCKED until actual required checks pass: backend MCP, real manual registration/check-in, coord plugin activation, protected human unlock, native tool credential isolation, and selected native Git/merge/deploy restrictions. Sign-in is independent of credential isolation. No protected unlock or cached-keychain behavior is simulated as a passing host check. No selected backend/remote or second distinct machine is assumed. Rerun actual qualification when any relevant harness, auth, permissions, policy or adapter configuration changes; discovery output is never an admission token.

Tests use fake canaries to prove that captured help/plugin/auth output cannot enter the JSON report, exercise time/output bounds, verify fixture labeling, and run real disposable Git/process primitives. Native qualification, selected remote policies, actual human unlock and two-machine A1–A7 remain external evidence requirements.
